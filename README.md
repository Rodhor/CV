# 🌍 Chris Nielsen – Developer Portfolio

A modern, multilingual portfolio built with **SvelteKit** and **Tailwind CSS**, showcasing projects and experience in English and German.

---

## Updating content

Edit `src/lib/data/projects.json` and `src/lib/data/cv.json`; both files link to their JSON schemas for editor completion and validation. Add English and German text together, then run `npm run check` before building.

```sh
npm install
npm run dev
```

## ✨ Features

- ⚡ **SvelteKit + Tailwind CSS** — modern, fast, responsive.
- 🌐 **Multilingual** — English 🇬🇧 and German 🇩🇪
- 🧱 **Component-based** — modular structure (Header, Footer, Sections, Modal).
- 📜 **JSON-driven data** — CV and Projects loaded from typed JSON.
- 🎬 **Smooth UX** — transitions, responsive design, and accessibility.
- 🚀 **Netlify-ready** — built with `@sveltejs/adapter-netlify`.
